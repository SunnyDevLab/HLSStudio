Security & Antivirus — Why the App May Not Open or Run 安全与杀毒软件 — 程序无法打开或无法运行的原因

HLS Studio is an independently developed Windows application. It is not a virus. However, because it is a newly packaged desktop program (often distributed outside major app stores), and because it includes components such as an embedded browser engine used only to analyze page network requests, some antivirus products may treat it as “unknown,” “potentially unwanted,” or even quarantine the executable.

This can completely prevent the software from opening or running — for example: the installer/exe is deleted after download; double-click does nothing; Windows shows “Windows protected your PC”; the process starts and exits immediately; browser analysis fails because related files were removed.

Important: A security warning does not necessarily mean the file is malicious, but it should always be taken seriously. Only proceed after you have confirmed the package came from a trusted release source.

How to resolve (recommended order)

  1. Confirm the source — Only use the official release channel. Do not run copies from unknown re-uploads.
  2. Check security history — Open your antivirus “Protection history” / quarantine. Note the detection name and the exact file path (e.g. HLSStudio.exe).
  3. Restore the file — If it was quarantined, restore it from quarantine so the program can start again.
  4. Add an exclusion (allow list) — Add the install folder or the main executable to exclusions / trusted files, for example:
    • Windows Security → Virus & threat protection → Manage settings → Exclusions → Add the HLS Studio folder
    • Or the equivalent “Trusted zone / Allow list” in third-party antivirus (360, Huorong, Kaspersky, etc.)
  5. SmartScreen (Windows) — If you see “Windows protected your PC”: click More info → Run anyway only after you trust the source.
  6. Re-download — After restoring and excluding, download again if the original file was deleted, then verify integrity when a SHA-256 checksum is published.
  7. Report false positives — Send the detection name, product version, and file hash to us so we can submit the build for vendor review. Please do not turn off antivirus entirely.

Safe practice: Prefer folder-level exclusion for the official install directory over disabling real-time protection. Keep your antivirus enabled.

Please do not disable antivirus protection or bypass security warnings unless the file has been independently verified as safe and you understand the risk.

Introduction 简介

HLS Studio is a Windows desktop application designed to make detecting, downloading, and archiving HLS video streams easier.

Many online video platforms deliver media as segmented streams rather than a single file. HLS Studio helps simplify this process with a dedicated desktop interface and practical tools for working with compatible media streams.

It is intended for video research, media archiving, and other legitimate workflows involving content you are authorized to download.

HLS Studio 是一款 Windows 桌面应用，用于更方便地检测、下载与归档 HLS 视频流。

许多在线视频平台以分段流媒体而非单一文件传输内容。HLS Studio 提供专用桌面界面和实用工具，帮助你处理兼容的媒体流。

本软件面向视频研究、媒体归档等合法场景，仅应用于你有权下载或归档的内容。

How to Use 使用说明

1. Launch & AI Analysis

  • Start HLS Studio and open the main workspace.
  • The app can automatically invoke large AI models to analyze online video pages and related media requests.
  • Based on the analysis result, it performs the corresponding detection and download processing for compatible streams.

2. Prepare a Task

  1. Video page URL — Paste the page URL of content you are authorized to download or archive.
  2. Network — Optionally enable a proxy (e.g. http://127.0.0.1:7890) and set concurrent download workers.
  3. Visible browser — Enable this if the site requires manual play, login, or CAPTCHA before media requests appear.
  4. Output — Choose an output folder and file name.

3. Start Download

  • Click Start Download. The app analyzes the page with AI assistance and processes compatible video streams.
  • Background mode — Automatically detects video streams and related media requests on the page.
  • Visible browser mode — Play the desired video in the opened window, then click the red Download Playing Video button at the top of the page. Keep the browser open to switch videos and download more; close the window when finished.
  • Watch progress and the run log. You can cancel a running task at any time.

1. 启动与智能分析

  • 启动 HLS Studio，进入主工作界面。
  • 程序可自动调用 AI 大模型，分析网络视频页面及相关媒体请求。
  • 根据分析结果，对兼容的视频流进行相应的检测与下载处理。

2. 准备任务

  1. 视频页面 URL — 粘贴你有权下载或归档的视频页面地址。
  2. 网络设置 — 可按需启用代理（例如 http://127.0.0.1:7890），并设置并发下载数。
  3. 可见浏览器 — 若站点需要手动点击播放、登录或过验证码后才会发出媒体请求，请勾选此项。
  4. 输出设置 — 选择输出目录与文件名。

3. 开始下载

  • 点击开始下载。程序将借助 AI 分析页面，并对兼容的视频流做相应处理。
  • 后台模式 — 自动检测页面中的视频流及相关媒体请求。
  • 可见浏览器模式 — 在弹出的窗口中播放目标视频，然后点击页面顶部红色下载正在播放的视频按钮。浏览器可保持打开以切换其它视频继续下载；全部完成后请手动关闭浏览器窗口。
  • 关注进度条与运行日志。可随时取消正在进行的任务。
